# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Living Skies Atlas: a static, no-backend Vite + TypeScript web app that maps Saskatchewan's safety, justice and land in open data on a 3D map (MapLibre basemap + deck.gl layers + d3 charts). It is the Saskatchewan sibling of Island Atlas (`C:\HouseShopping-VancouverIsland`) and keeps its framework, look and conventions; `MAP-ATLAS-BLUEPRINT.md` describes them, with this atlas's brief filled in as Part 1.

## Commands

```bash
npm run dev               # http://localhost:5173 (.claude/launch.json: "living-skies")
npm run build             # tsc --noEmit + vite build: the only automated check (no tests, no linter)
npm run data [stage…]     # rebuild public/data/*.json from the original sources
```

Data stages (in run order): `province places fires tornadoes hail rivers climate smoke drought normals population crime housing tax jobs needs treaties justice hospitals camping schools internet community newcomer doctors childcare industry water radon light transit commute`. `places` writes `municipalities.json`, which `jobs`, `needs`, `justice`, `hospitals`, `camping`, `schools`, `newcomer`, `doctors`, `childcare`, `industry`, `water`, `radon` and `commute` read; `schools`, `internet`, `community`, `doctors`, `childcare`, `industry` and `radon` also read `needs.json` (town limits); `doctors` reuses `hospitals`' ODHF download and `needs`' Overpass answer (`NEEDS_KINDS`, `needsOSM`); `community` reuses `censusProfile` and caches the characteristic codelist in `.cache/census/CL_CHARACTERISTIC.xml`. `internet` streams ~400 MB of ISED zips once and caches Saskatchewan's pseudo-households in `.cache/internet/sk-phh-speeds.tsv`. `water` reads the province's two advisory PDFs with a small text extractor (`pdfText`, `advisoryRows`) and places them with the CGNDB gazetteer (cached per feature type in `.cache/cgndb/sk-<TYPE>-<skip>.json`); its downloads cache per day in `.cache/water/`. `industry` pages ~120,000 well rows from the GeoHub (60 requests, cached in `.cache/arcgis/sk-wells-*`) and caches the latest NPRI single-year CSV (~40 MB) in `.cache/npri/`. `smoke` streams NAPS's yearly all-Canada PM2.5 files and caches only their Saskatchewan rows in `.cache/naps/` (a year with none yet is not cached, so it is fetched again next run). `drought` reads `municipalities.json` and the province outline and asks AAFC's drought image service for each month's raw categories (`exportImage`, `format=bsq`: the bytes are followed by a 1-bit mask, so only the first w×h are read) on a 10 km Web Mercator grid, one request a month cached in `.cache/drought/`; the catalogue is cached per day. `hail` reads `municipalities.json` (to place a research-database storm whose point is off the map) and joins the Northern Hail Project's per-bend swath pieces back into one track. `radon` reads Health Canada's survey CSV and StatCan's 2007 health region shapefile (Statistics Canada Lambert, parsed and unprojected in the stage; no shapefile library) from `.cache/radon/`. `transit` reads `needs.json` (town limits) and caches OurAirports' CSV and the four city GTFS zips in `.cache/transit/`; it keeps only each route's longest shape. `tax` reads the Ministry of Government Relations' latest Mill Rate Survey workbook (Publications Centre product 72573, cached in `.cache/tax/`; when the Publications Centre answers 502 it uses the Internet Archive's copy of the same URLs) with a small xlsx reader (columns found by header text), and reads `municipalities.json` and `housing.json` (median home value for the indicative tax). `light` computes day length and geomagnetic latitude itself and reads `camping.json` (park outlines, campgrounds) and `province.json`; it caches IAGA's IGRF-14 coefficient file and RASC's dark-sky table in `.cache/light/`. Raw downloads cache in `.cache/`; a failing stage keeps its old JSON and records the error in `public/data/manifest.json`. `public/data/` is committed.

## Rules for this repo

- All data comes from `npm run data` stages, never hand-edited JSON. The only hand-typed data is the place-name list in `scripts/places.mjs`, the curated events in `src/layers.ts` (`CURATED_EVENTS`, well-documented facts only, each with a source link) and the province's settlement-services list `SK_SETTLEMENT` in the `newcomer` stage of `scripts/fetch-data.mjs` (typed from saskatchewan.ca, with its source link and the date read in `SK_SETTLEMENT_ASOF`; re-check it when rebuilding).
- Anything from outside the code (OSM names, data strings) goes through `esc()` / `safeUrl()` in `src/html.ts` before `innerHTML`. The production build ships a CSP (`vite.config.ts`).
- Say when a value is inferred or borrowed: the in-town police rule (`nearestJustice` in `src/justice.ts`), borrowed climate stations, rural RCMP detachments standing in for a town.
- When you change a behaviour the blueprint describes (layer menu rules, event panels), update `MAP-ATLAS-BLUEPRINT.md` and the README with it.

## Architecture

Same shape as Island Atlas:

- **`src/main.ts`** owns state (`visible`, `focused` — `'province'` means none active — `timeLayer`, `mode: layer | town | finder | event`), the frame loop, the layer menu (`setLayerOn`, `focus`, `clearMap`), click routing and the timeline. `?film` exposes `window.atlas`.
- **`src/layers.ts`**: the `AtlasLayer` contract, shared helpers (exported for the layer modules), and the fires, rivers, climate, normals, population, crime and hospitals layers, `CURATED_EVENTS`, the base `province` layer and `buildLayers()`.
- **`src/justice.ts`** (Courts & police), **`src/treaties.ts`** (Treaties & reserves), **`src/camping.ts`** (Camping & rec), **`src/tornado.ts`** (Tornadoes), **`src/hail.ts`** (Hail), **`src/drought.ts`** (Drought), **`src/schools.ts`** (Schools & learning), **`src/internet.ts`** (Internet & mobile), **`src/community.ts`** (Who lives here), **`src/newcomer.ts`** (Newcomer services), **`src/doctors.ts`** (Doctors & clinics), **`src/childcare.ts`** (Childcare), **`src/smoke.ts`** (Smoke & air), **`src/industry.ts`** (Hidden neighbours), **`src/water.ts`** (Drinking water), **`src/light.ts`** (Light & dark), **`src/transit.ts`** (Getting around), **`src/commute.ts`** (Workday Reach; its workplace setting lives in `metrics.ts` and is shared with the Finder): one layer each.
- **`src/metrics.ts`**: `townMetrics(data)` per place and the Town Finder `CRITERIA` / `rankTowns`. **`src/panels.ts`**: Town Report and Town Finder. **`src/sources.ts`**: the Data & sources view. **`src/events.ts`**: the event/feature panel.
- **`src/data.ts`**: `loadAll()`, the JSON types, formatters.
- **`scripts/fetch-data.mjs`**: one async function per stage in `SOURCES`; helpers for caching, OGC API, ArcGIS REST, Overpass (with mirrors) and OSRM drive times (`driveTimes`).

## Data notes

- Crime: each place takes one police service's series (its own municipal one while current, otherwise the rural RCMP detachment of the same name); series are never spliced.
- Fires: CNFDB cause codes are `N` (natural/lightning), `H` (human), `H-PB` and `RE` (dropped), `U`.
- Internet: ISED tiers are what is offered (not measured); "Fixed 50/10" includes fixed wireless, excludes satellite; mobile is LTE or better (no 5G in the open data). Hexagons are drawn from ISED's centres as flat-topped hexagons (0.1206° wide spacing, rows 0.0168°/cos(lat) apart).
- Who lives here: census counts are randomly rounded to 5, so a share on a rounded 0 shows "—" (`pctText` in `src/community.ts`); the Finder's Diverse community is the immigrant share only. Reserves are separate CSDs, not in a town's Indigenous identity share.
- Newcomer services: settlement offices are read as text from IRCC's locator script (`services-info.js`, never run); Service Canada and SGI issuers are OSM only, and insurance brokers stand in for SGI issuers (inferred; say so).
- Doctors & clinics: clinics are ODHF SHA sites plus OSM (merged when close with the same first name word); ODHF sites with no point sit at their town centre (`approx`); a place with no clinic mapped but a hospital in town gets `h` and counts that hospital as its clinic (inferred, like the in-town police rule). SHA service disruptions are web notices only, so none are mapped; a clinic is not a doctor taking new patients (say so).
- Childcare: the Ministry of Education's regulated list is read from the saskatchewan.ca finder page (its `<li>` list and the parallel `window.pageList` points, as text). Crown copyright, non-commercial only. Family homes keep no name or address: a count per community at a point rounded to 0.02°. No capacity in the source; listings with no type are classed by name (inferred).
- Schools: the ministry list gives grades only for band schools; provincial schools' elementary/high comes from the name, and an unstated one counts as K-12 (`gi`) when no stated high school is within 10 km. The ministry layer misplaces ~⅓ of schools, so each snaps to a same-named OSM school within 30 km; schools it lacks inside the 62 places' limits are added from OSM (sector `osm`, never French). Drives skip Hutterite colony, band and independent schools.
- Radon: Health Canada's 2009–2011 survey by 2007 health region (the three northern RHAs pooled as `4714`) and FSA; each place takes the region its centre is in and its city FSAs (≥¼ of its town-limit outline points, or holding its centre), else its rural FSA. FSAs with under 20 tests are "few tests". The Finder's Lower radon uses the region share (weight 0).
- Light & dark: computed, not measured (say so). Day length for the build year (NOAA equations, 90.833° / 96°); aurora bands are NOAA SWPC's Kp rule (oval edge ≈ 66° − 2°·Kp) on the IGRF-14 centred-dipole geomagnetic latitude, never a probability; geomagnetic latitude is shown rounded down (`mlText`) so it never reads across a band edge. Dark-sky preserves come from the RASC table matched to park names (Sask. parts only); OMB Nocturnal Preserve has no open outline.
- Getting around: scheduled service is OurAirports' flag (not a timetable); OSRM routes over OSM winter roads, so far-north airports count as drive targets (the stage warns if one is ever nearest). Intercity bus and VIA come from OSM only (bus coverage partial: say so). Moose Jaw's GTFS has expired and Prince Albert's is the Mobility Database's copy; neither states a licence. The Finder's Can live without a car counts what is mapped in town, not frequency.
- Property tax: a Home costs chip, not its own layer (`tax.json`). Indicative only (say so): 2021 census median value × 80 % (residential percentage of value) × (uniform mill rate × residential factor + residential education rate, the median of the places' school levy ÷ assessment) ÷ 1000; base tax, minimum tax, library and special levies are flagged but never added. Lloydminster (own charter) gets a rate but no estimate.
- Overpass is often at capacity; the client retries across mirrors and caches only complete JSON.

## Verifying in the browser

Load `/?film`, wait for the map, then e.g. `atlas.clearMap(); atlas.focus('crime'); atlas.setTime(2024.5)` or `atlas.openTown('north battleford')`. When the browser pane is hidden the map's frame loop is throttled; take a screenshot before trusting a visual check.
