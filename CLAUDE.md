# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Living Skies Atlas: a static, no-backend Vite + TypeScript web app that maps Saskatchewan's safety, justice and land in open data on a 3D map (MapLibre basemap + deck.gl layers + d3 charts). It is the Saskatchewan sibling of Island Atlas (`C:\HouseShopping-VancouverIsland`) and keeps its framework, look and conventions; `MAP-ATLAS-BLUEPRINT.md` describes them, with this atlas's brief filled in as Part 1.

## Commands

```bash
npm run dev               # http://localhost:5173 (.claude/launch.json: "living-skies")
npm run build             # tsc --noEmit + vite build: the only automated check (no tests, no linter)
npm run data [stage…]     # rebuild public/data/*.json from the original sources
npm run data now          # the five live stages only (public/data/now/, not committed)
npm run data now history  # …and roll them into the daily record (public/data/history/, the data-history branch)
.venv/Scripts/python.exe video/render.py --storyboard   # the explainer film's storyboard (README: The explainer film)
```

The explainer film (`video/render.py`, scenes in `video/storyboard.py`) drives the app by its Layer menu names and DOM selectors (`#layers-btn`, `.layer-row`, `#panel .work-sel`, `.weight input[data-id]`, `[data-preset]`, `.src-go`): when a feature it films changes, update the storyboard and re-render it.

Data stages (in run order): `province places subdivisions tracts fires tornadoes hail rivers floods climate smoke drought crops normals projections population crime housing tax jobs needs treaties justice hospitals camping schools internet community newcomer doctors childcare industry power water radon light transit commute now-rivers now-fires now-air now-alerts now-outlooks`. `subdivisions` writes `subdivisions.json`: every Saskatchewan census subdivision (StatCan's 2021 boundary MapServer layer 9, cached in `.cache/arcgis/csd-47-all-*`; population and dwellings from `censusProfileAll`), with `k` linking the 62 places' own; it reads `municipalities.json` for that link only. `housing`, `jobs` and `community` also write a `csd` table keyed by CSD uid for every subdivision (`censusProfileAll`, 25 subdivisions a request, cached as `.cache/census/<tag>all-*.csv`). `tracts` reads `subdivisions.json` (city limits) and writes the 2021 census tracts of the Regina (705) and Saskatoon (725) CMAs with census values (DF_CT; SDMX codes are the DGUID with `.` → `_`), `out` marking tracts outside the city; It also reads each city's neighbourhood outlines (Regina `OpenData/Subdivisions/MapServer/5`, Saskatoon `OD/LandSurface/MapServer/0`) for names only. `src/tracts.ts` draws them as an SVG map at the top of those two Town Reports; d3 needs the rings rewound (clockwise). No neighbourhood crime: Regina Police's area workbooks and 90-day FeatureServer carry no licence, Saskatoon publishes city-wide only. `places` writes `municipalities.json`, which `jobs`, `needs`, `justice`, `hospitals`, `camping`, `schools`, `newcomer`, `doctors`, `childcare`, `industry`, `water`, `radon` and `commute` read; `schools`, `internet`, `community`, `doctors`, `childcare`, `industry` and `radon` also read `needs.json` (town limits); `doctors` reuses `hospitals`' ODHF download and `needs`' Overpass answer (`NEEDS_KINDS`, `needsOSM`); `community` reuses `censusProfile` and caches the characteristic codelist in `.cache/census/CL_CHARACTERISTIC.xml`. `internet` streams ~400 MB of ISED zips once and caches Saskatchewan's pseudo-households in `.cache/internet/sk-phh-speeds.tsv`. `water` reads the province's two advisory PDFs with a small text extractor (`pdfText`, `advisoryRows`) and places them with the CGNDB gazetteer (cached per feature type in `.cache/cgndb/sk-<TYPE>-<skip>.json`); its downloads cache per day in `.cache/water/`. `industry` pages ~120,000 well rows from the GeoHub (60 requests, cached in `.cache/arcgis/sk-wells-*`) and caches the latest NPRI single-year CSV (~40 MB) in `.cache/npri/`. `smoke` streams NAPS's yearly all-Canada PM2.5 files and caches only their Saskatchewan rows in `.cache/naps/` (a year with none yet is not cached, so it is fetched again next run). `drought` reads `municipalities.json` and the province outline and asks AAFC's drought image service for each month's raw categories (`exportImage`, `format=bsq`: the bytes are followed by a 1-bit mask, so only the first w×h are read) on a 10 km Web Mercator grid, one request a month cached in `.cache/drought/`; the catalogue is cached per day. `fires` also reads the National Burned Area Composite from CWFIS's GeoServer (WFS 1.0.0, `public:nbac`, EPSG:4326, one Saskatchewan year per request, ~20 MB for a big year, cached in `.cache/nbac/`; the year list is cached per day) and links each outline to the same-year start points inside it. `crops` reads `municipalities.json` and the province outline and asks AAFC's `annual_crop_inventory/<year>` image services for raw categories (`exportImage`, `format=bsq`, U8) sampled at 500 m in three strips a year (cached in `.cache/crops/`, ~6 MB a year), folding each 6 × 6 block into a 3 km Web Mercator cell's most common class. `power` reads `municipalities.json` and `needs.json` (town limits) and two Overpass answers (`sk-power-lines.json`, `sk-power-sites.json`). `hail` reads `municipalities.json` (to place a research-database storm whose point is off the map) and joins the Northern Hail Project's per-bend swath pieces back into one track. `radon` reads Health Canada's survey CSV and StatCan's 2007 health region shapefile (Statistics Canada Lambert, parsed and unprojected in the stage; no shapefile library) from `.cache/radon/`. `projections` reads ECCC's CanDCS-U6 30-year coverage on GeoMet (`climate:candcsu6:projected:annual:P30Y-Avg/coverage`, `subset=scenario(…),percentile(…),P30Y-Avg(…)`; 18 province grids cached in `.cache/projections/`) and samples each place's cell. `floods` reads the Water Security Agency's `1_500yr_Flood` and `Flood_Hazard_All` FeatureServers (cached in `.cache/arcgis/wsa-flood-*`). `hospitals` and `justice` (courts) keep each place's three fastest sites by road (`driveTimes` `keep`), which the closure scenarios fall back on. `transit` reads `needs.json` (town limits) and caches OurAirports' CSV and the four city GTFS zips in `.cache/transit/`; it keeps only each route's longest shape. `tax` reads the Ministry of Government Relations' latest Mill Rate Survey workbook (Publications Centre product 72573, cached in `.cache/tax/`; when the Publications Centre answers 502 it uses the Internet Archive's copy of the same URLs) with a small xlsx reader (columns found by header text), and reads `municipalities.json` and `housing.json` (median home value for the indicative tax). `light` computes day length and geomagnetic latitude itself and reads `camping.json` (park outlines, campgrounds) and `province.json`; it caches IAGA's IGRF-14 coefficient file and RASC's dark-sky table in `.cache/light/`. Raw downloads cache in `.cache/`; a failing stage keeps its old JSON and records the error in `public/data/manifest.json`. `public/data/` is committed, except `public/data/now/`.

The live stages (`now-*`; `npm run data now` runs all five) cache nothing and write `public/data/now/<name>.json` with `asOf`, `fetched`, `source`, `sourceUrl` and the licence, and their own `now/manifest.json` (merged by `loadAll`), so they never change a committed file. `now-rivers` reads `rivers.json` (gauges, `median`) and pages `hydrometric-realtime` for the last 24 h; `now-fires` reads CWFIS's GeoServer WFS 1.0.0 (2.0.0 with EPSG:4326 swaps the bbox axes) for `hotspots_last24hrs` and `m3_polygons_current` (season to date; kept while heat was seen within 7 days); `now-air`, `now-alerts` and `now-outlooks` read `municipalities.json`; `now-outlooks` reads the thunderstorm outlook (OGC API), CWFIS's `fdr_current_shp` (WFS 1.0.0, the day from its WMS title) and RAQDPS's `Sfc_PM2.5-WildireSmokePlume-DMax` (sic) by WMS GetFeatureInfo per place (kg/m³ × 1e9 = µg/m³); a part that fails is left out. `.github/workflows/live.yml` runs `npm run data now water`, builds and deploys hourly; it and `deploy.yml` first download the `now/` files the site serves, so a failed feed keeps its last file.

## Rules for this repo

- All data comes from `npm run data` stages, never hand-edited JSON. The only hand-typed data is the place-name list in `scripts/places.mjs`, the curated events in `src/curated-events.ts` (`CURATED_EVENTS`, well-documented facts only, each with a source link) and the province's settlement-services list `SK_SETTLEMENT` in the `newcomer` stage (`scripts/stages/newcomer.mjs`) (typed from saskatchewan.ca, with its source link and the date read in `SK_SETTLEMENT_ASOF`; re-check it when rebuilding).
- Anything from outside the code (OSM names, data strings) goes through `esc()` / `safeUrl()` in `src/html.ts` before `innerHTML`. The production build ships a CSP (`vite.config.ts`).
- Say when a value is inferred or borrowed: the in-town police rule (`nearestJustice` in `src/justice.ts`), borrowed climate stations, rural RCMP detachments standing in for a town.
- When you change a behaviour the blueprint describes (layer menu rules, event panels), update `MAP-ATLAS-BLUEPRINT.md` and the README with it.

## Architecture

Same shape as Island Atlas:

- **`src/main.ts`** owns state (`visible`, `focused` — `'province'` means none active — `timeLayer`, `mode: layer | town | finder | event`), the frame loop, the layer menu (`setLayerOn`, `focus`, `clearMap`), click routing and the timeline. `?film` exposes `window.atlas`.
- **`src/layer-kit.ts`**: the `AtlasLayer` contract (`Ctx`, `AtlasEvent`, `TimedEvent`, `RecentSpan`) and the helpers every layer module shares (`rgb`, `kicker`, `heroStats`, `deferChart`, `townColumns`, `dashExt`…). Layer modules import from it, never from `layers.ts`, so there is no import cycle.
- **`src/layers.ts`**: the registry only: `buildLayers()` (menu order) and the base `province` layer. **`src/curated-events.ts`**: `CURATED_EVENTS`.
- **`src/fires.ts`** (Wildfires), **`src/rivers.ts`** (River floods), **`src/climate.ts`** (Climate), **`src/normals.ts`** (Climate normals), **`src/population.ts`** (Population), **`src/crime.ts`** (Crime severity), **`src/hospitals.ts`** (Hospital access), **`src/justice.ts`** (Courts & police), **`src/treaties.ts`** (Treaties & reserves), **`src/camping.ts`** (Camping & rec), **`src/tornado.ts`** (Tornadoes), **`src/hail.ts`** (Hail), **`src/drought.ts`** (Drought), **`src/crops.ts`** (What grows here), **`src/schools.ts`** (Schools & learning), **`src/internet.ts`** (Internet & mobile), **`src/community.ts`** (Who lives here), **`src/newcomer.ts`** (Newcomer services), **`src/doctors.ts`** (Doctors & clinics), **`src/childcare.ts`** (Childcare), **`src/smoke.ts`** (Smoke & air), **`src/industry.ts`** (Hidden neighbours, with the power grid), **`src/water.ts`** (Drinking water), **`src/light.ts`** (Light & dark), **`src/transit.ts`** (Getting around), **`src/commute.ts`** (Workday Reach; its workplace setting lives in `metrics.ts` and is shared with the Finder): one layer each.
- **`src/scenario.ts`**: what-if closures (hospitals, courthouses): closed sites, `scenarioTrip`, `affectedTowns`, the panel box; `main.ts` draws the banner on `atlas:scenario`. Never read by `metrics.ts`. **`src/projections.ts`**: climate projection helpers (`projAt`, `provinceBand`, the Town Report row); `AtlasLayer.projection` hatches the timeline past the record, and `bandChart` (charts.ts) draws record bars then bands.
- **`src/now.ts`**: the live-reading rules (ages, 3 h stale, 24 h not drawn, `NOW_T`, `isNow`), the Right now block, weather alerts (`alertsInEffect` by layer, dashed outlines, the alert panel) and AQHI colours. Rivers, fires and smoke carry `AtlasLayer.now` (`asOf`, `archiveEnd`, `build`); `main.ts` draws `now.build` at the Now stop, hatches the gap after `archiveEnd` and opens such a layer at Now.
- **`src/history.ts`**: the daily record in the app: `dayT`/`tDay` (Saskatchewan day ↔ timeline time), `ensureFeed` (loads a feed's month files once, when the timeline enters a layer's recent span), and per-feed views (`riversHistory`, `firesHistory`, `airHistory`, `waterHistory`). A layer's `now.recent` (`RecentSpan` in `layer-kit.ts`) draws it; `main.ts` hatches only up to its first day and draws its sparkline dashed.
- **`src/metrics.ts`**: `townMetrics(data)` per place and the Town Finder `CRITERIA` / `rankTowns`, with the Finder weights saved in the browser (`loadWeights`, `saveWeights`). **`src/panels.ts`**: Town Report and Town Finder. **`src/sources.ts`**: the Data & sources view. **`src/events.ts`**: the event/feature panel.
- **`src/data.ts`**: `loadAll()`, the JSON types, formatters.
- **`scripts/fetch-data.mjs`**: the runner only: the stage `ORDER`, `npm run data now`, the manifests. Each stage is `scripts/stages/<name>.mjs`, whose default export does the work and is imported only when it runs. Shared helpers live in `scripts/lib/`: `config` (paths, `BBOX`, endpoints), `io` (`log`, `cached`, `fetchBuf`, `writeOut`, `writeNow`, `pool`), `apis` (OGC API, ArcGIS REST, Overpass with mirrors, StatCan WDS), `parse` (CSV, fractional years, `pdfText`/`advisoryRows`), `geo` (distances, `dp`, `vwRing`, `joinPaths`, `edgeKm`), `places` (`getProvince`, `inSask`, `getPlaces`, `getSmallPlaces`, `smallAreas`, `straightTimes`; the `places` stage primes them with `setPlaces`/`setSmallPlaces`), `drive` (OSRM, `driveTimes`), `census` and `needs-osm` (`NEEDS_KINDS`, `needsOSM`, the ODHF rows). A new stage gets its own file and a place in `ORDER`.

## Data notes

- Crime: each place takes one police service's series (its own municipal one while current, otherwise the rural RCMP detachment of the same name); series are never spliced.
- Fires: CNFDB cause codes are `N` (natural/lightning), `H` (human), `H-PB` and `RE` (dropped), `U`. Burn outlines are NBAC's for burns of 200 ha or more (prescribed ones dropped), simplified by Visvalingam–Whyatt (`vwRing`: triangles of a sixth of the burn's width; Douglas–Peucker left spikes on its pixel-stepped edges), parts under 40 ha and islands under 200 ha dropped. A row is `[year, ha, polys, t, start-point indices]`; a start point inside a same-year outline (or within 1 km of its edge) draws no circle. NBAC's area is its own (less unburned islands), not the reported size.
- What grows here: each 3 km cell is its most common class of 36 samples (cloud and unmapped ignored), so small fields vanish (say so). Eleven classes grouped from the inventory's codes in the stage (`group`); code 130, too wet to be seeded, is in “other crops and fallow” and makes 2010–11 stand out. Shares are over the cells mapped every year; a place's land is its cells within 25 km, null when under half are mapped. Coverage stops around 55–56° N.
- Power grid: OSM only (SaskPower publishes no open grid map; its outage feed is undocumented and unlicensed, so it is not used). Lines are grouped by voltage class (230, 138, 72 kV, 0 untagged) and joined end to end; a substation mapped as a point and an outline is kept once. A place measures the nearest line (sampled every ~250 m) and substation from its town limits; never in the Finder.
- Internet: ISED tiers are what is offered (not measured); "Fixed 50/10" includes fixed wireless, excludes satellite; mobile is LTE or better (no 5G in the open data). Hexagons are drawn from ISED's centres as flat-topped hexagons (0.1206° wide spacing, rows 0.0168°/cos(lat) apart).
- Tiers: `municipalities.json` holds the 62 (`tier: 1`) and 417 small communities (`tier: 2`, `csd` uid, placed at their CSD outline's area centroid). `getPlaces()` returns tier 1 only; `getSmallPlaces()` tier 2; `smallAreas()` their town limits from `subdivisions.json`; `straightTimes()` their nearest targets as `{ f, min: null, km }`. `jobs` (region only), `needs`, `justice`, `hospitals`, `doctors`, `childcare`, `schools`, `internet`, `drought`, `radon` and `light` write a `small` table beside `towns`; a tier-1 table never changes. Not for tier 2: crime, population (the app uses the CSD's census counts), camping, transit, commute, tax, crops, industry, water, newcomer, projections, places of worship. In the app `data.munis` stays the 62 and `data.small` holds tier 2; `smallView` (src/small.ts) merges the `small` tables and CSD census values so `townMetrics` and the Finder handle both; `rankTowns` skips tier 2 on `drive` criteria. `atlas:town` and `openPlace` route a key to the Town Report or `renderSmallReport`.
- Census subdivisions (`src/subdivisions.ts`): `csdTint` draws a census layer's measure for all 951 subdivisions under its columns; `csdReport` is the census-only report (an AtlasEvent via `describe`), and `csdClick` sends a click on a place's own subdivision to its Town Report or small-community report. Suppressed values are untinted and read "—" (`missing`); `ne` (an incompletely enumerated reserve, the data quality flag's first digit) reads "not enumerated"; a rural municipality excludes the towns inside it (say so). The Finder reads the 62 unless "Include small communities" is ticked.
- Who lives here: census counts are randomly rounded to 5, so a share on a rounded 0 shows "—" (`pctText` and `share` in `src/subdivisions.ts`); the Finder's Diverse community is the immigrant share only. Reserves are separate CSDs, not in a town's Indigenous identity share.
- Newcomer services: settlement offices are read as text from IRCC's locator script (`services-info.js`, never run); Service Canada and SGI issuers are OSM only, and insurance brokers stand in for SGI issuers (inferred; say so).
- Doctors & clinics: clinics are ODHF SHA sites plus OSM (merged when close with the same first name word); ODHF sites with no point sit at their town centre (`approx`); a place with no clinic mapped but a hospital in town gets `h` and counts that hospital as its clinic (inferred, like the in-town police rule). SHA service disruptions are web notices only, so none are mapped; a clinic is not a doctor taking new patients (say so).
- Childcare: the Ministry of Education's regulated list is read from the saskatchewan.ca finder page (its `<li>` list and the parallel `window.pageList` points, as text). Crown copyright, non-commercial only. Family homes keep no name or address: a count per community at a point rounded to 0.02°. No capacity in the source; listings with no type are classed by name (inferred).
- Schools: the ministry list gives grades only for band schools; provincial schools' elementary/high comes from the name, and an unstated one counts as K-12 (`gi`) when no stated high school is within 10 km. The ministry layer misplaces ~⅓ of schools, so each snaps to a same-named OSM school within 30 km; schools it lacks inside the 62 places' limits are added from OSM (sector `osm`, never French). Drives skip Hutterite colony, band and independent schools.
- Radon: Health Canada's 2009–2011 survey by 2007 health region (the three northern RHAs pooled as `4714`) and FSA; each place takes the region its centre is in and its city FSAs (≥¼ of its town-limit outline points, or holding its centre), else its rural FSA. FSAs with under 20 tests are "few tests". The Finder's Lower radon uses the region share (weight 0).
- Light & dark: computed, not measured (say so). Day length for the build year (NOAA equations, 90.833° / 96°); aurora bands are NOAA SWPC's Kp rule (oval edge ≈ 66° − 2°·Kp) on the IGRF-14 centred-dipole geomagnetic latitude, never a probability; geomagnetic latitude is shown rounded down (`mlText`) so it never reads across a band edge. Dark-sky preserves come from the RASC table matched to park names (Sask. parts only); OMB Nocturnal Preserve has no open outline.
- Getting around: scheduled service is OurAirports' flag (not a timetable); OSRM routes over OSM winter roads, so far-north airports count as drive targets (the stage warns if one is ever nearest). Intercity bus and VIA come from OSM only (bus coverage partial: say so). Moose Jaw's GTFS has expired and Prince Albert's is the Mobility Database's copy; neither states a licence. The Finder's Can live without a car counts what is mapped in town, not frequency.
- Property tax: a Home costs chip, not its own layer (`tax.json`). Indicative only (say so): 2021 census median value × 80 % (residential percentage of value) × (uniform mill rate × residential factor + residential education rate, the median of the places' school levy ÷ assessment) ÷ 1000; base tax, minimum tax, library and special levies are flagged but never added. Lloydminster (own charter) gets a rate but no estimate. The workbook's layout changes between years (2025 spells out the status, `City` for `C`, and says Education for School): the stage accepts both and throws when under 80 % of the places match, so a new layout keeps the old `tax.json`.
- The daily record (`scripts/history.mjs`, `npm run data history`, run on demand only, after `now`): lives on the **`data-history` branch**, never main; `live.yml` checks it out into `public/data/history/` (gitignored), rolls up, and its `archive` job (the only one with `contents: write`, runs no repository code) copies the result over the branch, additive only. **Never splice**: a recent span starts the first day after the archive's last year, so provisional days never join the official series and drop out of view once the archive publishes their year. A missed run is a gap, never a zero. Rivers and AQHI days are recomputed whole from the feeds' own windows; hotspots are de-duplicated by position and minute (CWFIS ids are not stable) and never feed the wildfire statistics; alerts continue a row when seen again within 6 h. `history-backfill` reaches back once (gauges ~30 days, AQHI ~3 days, CWFIS `public:hotspots` the whole season via WFS 2.0 with `srsName=CRS:84`).
- Right now: every live value shows its age (`ageTag`; `plainAge` for hotspots, whose list window is 24 h, so staleness comes from the list's read time). A river flag (`ice`, `est`) gets an amber ring; a silent gauge is "no reading", never zero. Hotspots are not confirmed fires (say so). AQHI is borrowed from the nearest community within 150 km, outside Saskatchewan included (`out`); never chart it with smoke days. Alerts are grouped by code and text, `esc()`'d, and a place is covered when its centre is in a region. Live values never feed the Finder.
- Scenarios and projections: a scenario is the visitor's own (banner, red, never in the Town Report or Finder); a projection is a model range (hatched, badged, a band, never a single value or a Finder criterion). Outlooks show issue and valid times and drop once valid time passes.
- Overpass is often at capacity; the client retries across mirrors and caches only complete JSON.

## Verifying in the browser

Load `/?film` (it skips the live readings; `/?film&now` loads them), wait for the map, then e.g. `atlas.clearMap(); atlas.focus('crime'); atlas.setTime(2024.5)` or `atlas.openTown('north battleford')`. When the browser pane is hidden the map's frame loop is throttled; take a screenshot before trusting a visual check.
