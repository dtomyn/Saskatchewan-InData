# Living Skies Atlas

*Saskatchewan's safety, justice and land, in open data.*

A static, animated 3D map of Saskatchewan built on the same framework as [Island Atlas](https://github.com/dtomyn/HouseShopping-VancouverIsland) (Vancouver Island). It combines a **justice & public-safety** view (crime severity, courts, police, corrections, treaties and reserves) with the hazards and services that matter when choosing where to live (wildfires, tornadoes, hail, river floods, climate, population, hospital access, parks and camping).

It is an exploration tool, not legal, safety or real-estate advice.

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + static build into dist/
```

`public/data/` is committed, so the app runs without the pipeline, except `public/data/now/`: the live readings (below) are fetched, not committed. Without them the River floods, Wildfires and Smoke & air panels show a dashed "Right now" box; `npm run data now` fills it.

**Dev container:** open the folder in VS Code and choose *Reopen in Container* (needs Docker and the Dev Containers extension). It uses Node 22, runs `npm ci` on creation, keeps `node_modules` in a named volume, and forwards port 5173, so `npm run dev` works as above.

## Refreshing the data

```bash
npm run data                    # every stage
npm run data crime justice      # selected stages
```

Stages, in run order: `province places subdivisions tracts fires tornadoes hail rivers floods climate smoke drought normals projections population crime housing jobs needs treaties justice hospitals camping schools internet community newcomer doctors childcare industry water radon light transit commute now-rivers now-fires now-air now-alerts now-outlooks`. Raw downloads cache in `.cache/`; a failing stage keeps its old JSON and records the error in `public/data/manifest.json`, which the Data & sources view shows. `justice`, `hospitals`, `camping`, `schools`, `newcomer`, `doctors` and `childcare` call the public OSRM demo router once a second, so a cold run takes about 10 minutes.

### Right now: the live readings

```bash
npm run data now                # now-rivers now-fires now-air now-alerts now-outlooks
```

Five stages read today's feeds and write `public/data/now/` (in `.gitignore`), never cached: the latest real-time level and flow at each gauge in `rivers.json` (last 24 hours), CWFIS satellite hotspots of the last 24 hours and the fire perimeters estimated from them, Environment Canada's AQHI observations and forecasts, the weather alerts in effect over Saskatchewan, and short-range outlooks (`now-outlooks`: MSC's thunderstorm outlook, CWFIS's fire danger class for today, and the next day's highest wildfire-smoke PM2.5 from ECCC's RAQDPS, which carries FireWork). They keep their own `now/manifest.json`, so running them changes no committed file.

On GitHub, `.github/workflows/live.yml` runs `npm run data now water`, builds and redeploys about once an hour (and on demand); `deploy.yml` runs the live stages too, so a push never deploys without them. Both start from the `now/` files the site is serving, so a feed that is down keeps its last reading. Scheduled runs can be late when GitHub is busy, and GitHub turns schedules off in a repository with no activity for 60 days (re-enable it under Actions), so the app never assumes a reading is fresh: see Caveats.

A layer with a live reading ends its timeline at **Now**, where it opens; the years between its archive and today are hatched ("no record yet") until the daily record begins.

### The daily record

```bash
npm run data now history            # roll today's readings into public/data/history/
npm run data now history-backfill   # once: reach back as far as each feed keeps
```

The hourly workflow also keeps a compact daily record of the live feeds, so the timeline runs from each archive's last year towards today and point-in-time layers gain a history: per gauge per day the lowest, highest and mean flow; every hotspot by day; each AQHI community's highest value per day; each weather alert and each drinking water advisory with the days it was in effect. One file per feed per month in `public/data/history/<feed>/`, plus `index.json`. They live on the **`data-history` branch**, not on main: `live.yml` checks it out before rolling up and its `archive` job (the only job allowed to push, and only there) appends the result. Clone it with `git clone -b data-history <repo> public/data/history` to see the record locally. To start the record, run the **Refresh live readings** workflow once by hand with **backfill** ticked. How far back it goes depends on the feed: the gauges keep about 30 days, AQHI about 3, CWFIS every season's hotspots; weather alerts and drinking water advisories start the day the record started. With `?film` the app skips the live files so the film stays repeatable; `?film&now` loads them.

## The explainer film

`video/` films a narrated how-to from the real app, one exact frame at a time (the framework from Island Atlas; `MAP-ATLAS-BLUEPRINT.md` Part 8). `video/storyboard.py` holds the scenes, narration, camera and sound: finding your way around, moving the map, layers and the timeline, the Settling in, Health and Around the property layers, a town report, Town Finder (workplace, sliders, the New to Saskatchewan preset), Data & sources and the shortcuts. The narration's counts come from the app's data, so re-film after `npm run data`.

Setup (once; needs Microsoft Edge for the GPU map):

```bash
uv venv .venv --python 3.12
uv pip install --python .venv/Scripts/python.exe playwright imageio-ffmpeg kokoro-onnx soundfile numpy
```

Put `kokoro-v1.0.onnx` and `voices-v1.0.bin` (github.com/thewh1teagle/kokoro-onnx releases) in `.venv/kokoro`. Then:

```bash
.venv/Scripts/python.exe video/render.py --check        # fill in every line from the data, no filming
.venv/Scripts/python.exe video/render.py --storyboard   # video/out/storyboard.html, script.md, captions, youtube.txt
.venv/Scripts/python.exe video/render.py --preview      # quick 960×540 cut with sound
.venv/Scripts/python.exe video/render.py                # 2560×1440 master + 1080p copy
```

Outputs land in `video/out/` (not committed). A layer renamed in the Layer menu must be renamed in `video/storyboard.py` too.

## Caveats

- **The daily record** is provisional and is never joined to the official archives: it is drawn only after an archive's last year, dashed on the sparkline, with a "provisional" badge, and a year drops out of view once HYDAT, the NFDB or NAPS publishes it. A day with no run is a gap, not a zero; a day built from few hourly runs is flagged. River days are each gauge's highest real-time flow against its normal annual peak. Recorded hotspots are not fires and never count in the wildfire statistics. AQHI days show on the map only, never on the smoke-day sparkline. Drinking water and weather alerts have no history before the record began, because their sources publish only what is in effect today.
- **Right now** readings are point-in-time and show their age everywhere: older than 3 hours they are greyed and labelled stale, older than 24 hours they are not drawn. Real-time river data are provisional; readings flagged ice-affected or estimated get an amber ring, and a silent gauge (many shut for the winter) shows "no reading", not zero. A **hotspot** is heat seen from a satellite, not a confirmed fire: gas flares, farm and slash burning and hot industrial sites show up too; the perimeters CWFIS estimates from them are drawn dashed. The **AQHI** is an index of three pollutants (ozone, nitrogen dioxide, fine particles), not the smoke-day count, and the two are never drawn together; a place without its own reading borrows the nearest community within 150 km (Cold Lake and Medicine Hat included), named in its report. Alert regions come from Environment Canada's forecast regions; a place is "covered" when its centre is inside one. Live readings never feed the Town Finder.
- **Crime** is reported by police service, not by town. Small towns' municipal RCMP series stop in 2011; after that the atlas uses the rural detachment of the same name, which also covers the surrounding area, including nearby First Nations. Northern detachments cover small populations, so their index swings hard on a few incidents. A high index in a service hub partly reflects people who come in from outside.
- **Courts and police** come from OpenStreetMap, which is incomplete here. Where Statistics Canada lists a place with its own current municipal police service but nothing is mapped near its centre, the atlas counts police as "in town" and says so. Provincial Court circuit points held in halls or band offices are mostly unmapped.
- **Home costs**: census values are 2021 (owners' own estimates of what their home would sell for; shelter costs include utilities) for each place's own census subdivision, with the smallest places' figures rounded or suppressed. CMHC's survey covers only purpose-built rentals of three units or more in 9 centres (Weyburn and smaller towns are not surveyed); each centre's rent and vacancy are for its whole metropolitan area or agglomeration and are shown only on the place it is named after (Saskatoon's includes Warman and Martensville). Lloydminster's census and rent figures are its Saskatchewan side; its vacancy rate covers both sides.
- **Property tax** is indicative, never a bill: the 2021 census median home value × 80 % ([residential percentage of value](https://www.saskatchewan.ca/government/news-and-media/2020/december/04/property-tax-percentages-of-value-updated-for-2021), unchanged for 2025–2028) × (the place's uniform municipal mill rate × its residential mill rate factor + the provincial residential education mill rate, 4.27 in 2025, read from the survey's education levies) ÷ 1000. Mill rates are the latest Mill Rate Survey the Publications Centre lists (2025, filed early in the year, so not the final levy). Assessment is not market value (the 2021 revaluation values homes as of January 1, 2019) and the census value is the owner's own guess. Base tax and minimum tax (used by most towns and some cities), library levies and special levies are not added, so many real bills are higher. Lloydminster is assessed under its own charter and gets no estimate; Cumberland House reported no rate in 2025. The workbook is Crown copyright with no open licence, and when the Publications Centre is down (HTTP 502) the stage falls back to the Internet Archive's copy of the same file.
- **Jobs & income**: Labour Force Survey rates are survey estimates for whole economic regions, not towns, so every place in a region shares one value (the Finder's Jobs nearby therefore ties many places), and a region's rate can move a point a year by chance. The LFS publishes Prince Albert and Northern only as one region, so they share a series and a tint. The survey leaves out people living on reserves. Table 14-10-0464-01 starts in 2011; it replaced 14-10-0393-01 (2006–2024, archived), and the two are not spliced. Each place takes the economic region its centre lies in. Census figures are 2021 for the place's own census subdivision: household income is 2020 income (a year of pandemic benefits); industries are the labour force by NAICS sector (people working, or who last worked, since January 2020); the in-town unemployment rate is census week, May 2021, in the pandemic.
- **Daily needs** come from OpenStreetMap, whose coverage is uneven: cities are well mapped, but in small towns a credit union, library, pharmacy or doctor's office is often missing (in this build Prince Albert and Yorkton show no library and Weyburn no bank), so a ✗ can mean "not mapped" rather than "not there". A site counts for a place when it lies inside the place's 2021 census subdivision (its municipal limits, not the surrounding rural municipality) or within 1 km of them. Grocery means a supermarket or grocery store, not a convenience or general store; a clinic means a clinic or doctor's office, not a hospital or health centre. The Town Finder's "Daily needs in town" counts how many of the eight are met; it replaced the old "Services & amenities" criterion (log of population), and a weight saved under the old one carries over.
- **Schools**: the ministry's list states grades only for First Nations band schools. A provincial school is counted as elementary or high from its name ("Elementary", "Middle", "Junior" / "High", "Collegiate", "Composite", "Comprehensive"); a name that says neither (most rural "… School") counts as elementary, and also as K-12 when no school that states high-school grades is within 10 km. That inference fits most one-school towns but not all, so check grades with the division. French immersion is only what the ministry's program field lists (immersion may cover some grades only); Fransaskois schools are for children with French-language education rights. The ministry's GeoHub layer places about a third of schools 1–20 km from the building and misses many (Estevan has none on it; Kindersley, Rosetown and Unity lack their high schools). So a listed school takes the position of the OpenStreetMap school of the same name within 30 km, and OpenStreetMap schools that match none, lie inside one of the 62 places' town limits (+1 km) and 300 m or more from every kept school are added, named or not (outside the towns OpenStreetMap maps many homestead-era schoolhouses; an unnamed one may duplicate a listed school that stayed misplaced); their sector is not stated unless OpenStreetMap says Catholic, and they never count as French. Drive times count public, separate, Fransaskois and those OpenStreetMap schools, not Hutterite colony, band or independent schools. Post-secondary sites are the Ministry of Advanced Education's list (regional colleges, SIIT, Gabriel Dumont Institute, the universities and their colleges) plus Saskatchewan Polytechnic's Regina, Moose Jaw and Prince Albert campuses from OpenStreetMap; it has no Sask Polytech campus but Saskatoon. Daily needs counts schools from OpenStreetMap alone (any school, private ones too), the Town Report's "Schools in town" from the merged list (only schools any family can attend), so the two can differ.
- **Internet & mobile**: ISED records where providers say a service is **offered** at a speed tier, not the speeds people get, how well a fixed-wireless or mobile signal reaches a given house, or what it costs. Fixed wireless counts towards 50/10 (hence the separate "By wire" view); satellite (Starlink and others) is offered almost everywhere and is not counted. ISED's top tier is 50/10, so a town with gigabit fibre and one with 50/10 fixed wireless both show "50/10+". Shares weight ISED's pseudo-households (road points carrying the 2021 census households near them) by households; a place counts those inside its 2021 census subdivision. Mobile is LTE or better: the open data does not single out 5G. Carriers are the mobile networks ISED lists per hexagon (SaskTel and Rogers in most towns), not resellers. Nearly every town gets 50/10, so the Finder's Fast internet mostly separates a few northern places; the map's rural hexagons are where it varies.
- **Inside the cities**: the Regina and Saskatoon Town Reports open with a map of their 2021 census tracts (home value, income, renters, stretched, immigrants, Indigenous identity), with the cities' own neighbourhoods outlined and named on hover. Census only: there is no neighbourhood crime map, because neither city's police publish neighbourhood counts with a reuse licence (Regina Police's area tables and 90-day map have none; Saskatoon Police publish city-wide figures only).
- **Small communities**: the 417 other cities, towns, villages, resort villages and northern municipalities (tier 2, from their 2021 census subdivisions) appear as faint blue dots and open a short report: census figures, what is mapped in town, hazards by location, and the nearest hospital, police, court, clinic, pharmacy, child care and school **in a straight line**, not by road (the public OSRM server cannot take several hundred more places, and the pipeline stays Node-only). They have no crime series of their own, and no camping, transit, commute, rent survey, property tax, crops, industry, water, newcomer or projection rows; the report says so row by row. In the Town Finder they join only when you tick "Include small communities", and then every drive-time criterion skips them, as does anything else they lack (skipped, never penalized): each row says how many of your weighted criteria it was scored on. Their school counts use the ministry's points as given (only the 62 places get OpenStreetMap gap-fill), which can be kilometres off.
- **Every census subdivision**: Home costs, Jobs & income (chip *Income by subdivision*) and Who lives here tint all 951 of Saskatchewan's 2021 census subdivisions, not only the 62 places; clicking one that is not an atlas place opens a census-only report (no crime, drive times or services). A value Statistics Canada suppressed is left untinted and reads "—", never zero; a share on a rounded 0 reads "—". A rural municipality surrounds its towns and villages but excludes them, so its figures are the countryside's alone. Reserves are their own subdivisions; one not fully enumerated in 2021 (the first digit of Statistics Canada's data quality flag) reads "not enumerated".
- **Who lives here** describes who already lives in a place, to help newcomers find community; it does not rank people. Census counts are randomly rounded up or down to a multiple of 5 and some small places' sample figures are suppressed, so a share built on a rounded 0 shows "—" (none, a handful, or not published) rather than 0%. Immigrants, birthplaces and Indigenous identity come from the 2021 long-form sample (one household in four, people in private households); languages from every household (home language counts people who gave a single language). Immigrants are people who are or have been permanent residents; temporary residents (students, work permits) are shown separately. Top birthplaces are named countries only ("other places in Asia" is left out), and the census names only ~60 countries, so a smaller community may not show. French is *knowledge* (can hold a conversation), with French mother tongue alongside. Figures are for the place's own census subdivision: First Nation reserves beside a town are their own subdivisions and are not in its Indigenous identity share (see Treaties & reserves). Places of worship come from OpenStreetMap: many small-town churches carry no religion tag (grey dots), and congregations meeting in halls or homes are not mapped. The Finder's Diverse community is the immigrant share alone, not a wider diversity index.
- **Newcomer services**: settlement and language offices are IRCC's own *Find free newcomer services* list, offices that serve people in person, with the services IRCC says each offers (many regional-college sites teach English only); "settlement help" counts offices offering general settlement help, needs assessments or community connections. IRCC-funded services are for permanent residents and some temporary residents. The province's list of settlement services (the Regional Newcomer Gateways) is not published as data, so it is **typed into the build script** from saskatchewan.ca with the date it was read (2026-11-12); it must be re-checked by hand, and the organisations on it that IRCC does not list (in Saskatoon, Tisdale and Lloydminster) are placed at their town's centre. Neither ESDC nor SGI publishes its office list as open data, so Service Canada offices and SGI motor licence issuers come from OpenStreetMap. Service Canada is fairly well mapped (scheduled outreach sites open on certain days only; Flin Flon, Manitoba, serves Creighton). SGI has nearly 400 issuers, mostly insurance brokers, and OpenStreetMap maps only some: insurance brokers count as issuers (most are, but this is **inferred**), so the nearest issuer is often closer than the atlas says. Health cards are applied for online, by mail, or at eHealth Saskatchewan in Regina only, so they are not mapped.
- **Getting around**: "scheduled service" is OurAirports' flag, not a timetable, so it can lag a route starting or ending, and a small northern airport may see only a few flights a week; airports just over the border (Lloydminster, Flin Flon) count,; far-north airports (Stony Rapids, Uranium City, Wollaston Lake…) are reached by air or winter road and never come out nearest for any place. Trains and intercity buses are only what OpenStreetMap volunteers have mapped: VIA's Canadian stops about twice a week each way and many stops are flag stops, and **intercity bus coverage is partial** (coach lines start, change and stop often), so a town may have a bus the atlas does not show. City buses come from each city's GTFS feed: Regina's and Saskatoon's are open data; Moose Jaw's timetable file expired in 2024 and Prince Albert's own link is gone (the Mobility Database's last copy is used), and neither states a licence. Other towns' buses are what OpenStreetMap has. The Finder's **Can live without a car** is a rough count of what is mapped in town (city bus 2, intercity bus 1, VIA stop 1), not how often anything runs; **Near an airport** is the drive to the nearest airport with scheduled flights.
- **Childcare**: the Ministry of Education's list of regulated centres and licensed family child care homes as shown on saskatchewan.ca, read from the page (the province publishes no data file). **Licensed does not mean a space is open**: waitlists are common, especially for infants. Parent fees for regulated spaces for children under six have been about [$10 a day since April 2023](https://www.saskatchewan.ca/government/news-and-media/2023/march/06/saskatchewan-to-achieve-$10-a-day-child-care-by-april-2023); unlicensed care is not on the list and not shown, nor is care on Lloydminster's Alberta side, which Alberta licenses. The list gives **no licensed capacity**, so spaces are not counted, only facilities. The ministry calls its points approximate, and some are far off (Unity's daycare sits 39 km north of town), so a facility whose point lies outside the atlas place its address names is moved to that place's centre and drawn faded (**approximate**). Family child care homes are people's homes, so their names and addresses are dropped: only a count per community is kept, at a point rounded to about 2 km (in-town counts use the home's own point during the build). About 70 listings give no type; they are classed as a centre or home by name (**inferred**). The page is Crown copyright, reproducible for non-commercial use only, which is narrower than the open licences elsewhere in the atlas.
- **Hidden neighbours** is neutral on purpose: the wells, plants and mines near a town are often where its jobs are. **Wells include abandoned and suspended ones**: the Ministry of Energy and Resources lists every well ever drilled (of 88,000 drilled wells, over half are abandoned and about a sixth suspended); each report splits them, and never-drilled planned or cancelled licences are left out. One well is one surface location (the source has a row per completion). Oil and gas facilities (batteries, satellites, injection and compressor sites, gas plants) are operating or built licences, placed at the centre of their licensed area. Pipelines are the province's licensed lines (in use or being built; abandoned and discontinued ones are neither drawn nor counted); the ~95,000 **flowlines** from wells to batteries are open too but not drawn or counted. The **Canada Energy Regulator publishes no open map of the lines it regulates**, so federal lines are the OpenStreetMap pipelines whose name or operator is a CER-regulated system (Enbridge, Keystone, Alliance, Foothills/Northern Border, the Dakota CO2 line), and some, such as parts of TC Energy's gas mainline, are missing. The **NPRI** lists only facilities above its reporting thresholds, and a release total adds up very different substances and says nothing about exposure. Mines are the producing mines in the Saskatchewan Mineral Deposit Index (helium wells left out) plus NPRI mine sites it lacks (new and project mines such as Jansen). Each place counts from its 2021 census town limits (or 3 km round its centre where none), and the Finder's **Fewer industrial neighbours** adds wells, facilities, NPRI sites, pipelines and a mine one each, so a pumpjack weighs the same as a gas plant.
- **Drinking water** is a snapshot of the advisories in effect the day the data was built (`npm run data water` refreshes it; downloads are cached per day). The province publishes the lists only as PDF reports, read as text by their layout, so a change of layout breaks the stage (it then keeps the old JSON). The lists give **no locations**: a dot is **inferred** from the town, park or reserve a system is named for, else from a place named in its listing (shown at that place, e.g. a speedway at Estevan), else the centre of a named lake (northern lodges, which can be tens of km off); about a third (lodges, rural pipelines, private businesses) name nothing findable and are counted in the panel but not mapped or counted near any place. "Town water system" matches the Water Security Agency's waterworks by the place's name, and says when only part of the system is affected. Some listings are years old (the province says a lifted advisory can stay listed). Most acreages draw on private wells, which no advisory covers; the [Water Security Agency](https://wsask.ca/drinking-water-wastewater/groundwater/domestic-water-well-management/) advises a bacteria test twice a year. No Finder criterion: an advisory is a point-in-time fact.
- **Radon** comes from Health Canada's Cross-Canada Survey (2009–2011): volunteer homes, about 100 per health region, each tested once (most for three months or more), so every share is a sample that can move several points by chance. The survey reports **2007 health regions** (the regional health authorities before the 2017 merger), so the map uses Statistics Canada's boundary file of that vintage, and it pooled the three northern regions into one. Postal areas (FSAs) are finer but are drawn on **2021** boundaries, and most city FSAs had only a handful of tests (under 20 is flagged "few tests"); a place's postal figure pools the city FSAs covering its town limits (else the rural FSA its centre is in), which is **inferred**. Newer testing points higher: the Evict Radon national study (University of Calgary) reports about one Saskatchewan home in three over the guideline, but its data are not open. Radon varies from house to house; the only way to know is a long-term test, which [Health Canada](https://www.canada.ca/en/health-canada/services/health-risks-safety/radiation/radon/test-your-home.html) advises for every home. The Finder's **Lower radon** (weight 0) uses the health region share: regions range from 7% to 26%, a real difference, but it is a regional odds, not a property's.
- **Light & dark** is computed, not measured. Day length is for the build year and the same at every longitude on a latitude; it ignores hills and the horizon. The aurora bands are NOAA's rule of thumb for where the auroral oval sits at each Kp (≈ 66° − 2° per Kp, geomagnetic), applied to a centred-dipole geomagnetic latitude from IGRF-14: they are not probabilities, and clouds, the moon and city lights decide what a night shows; an aurora is often visible low in the north from far south of the oval. Only the Saskatchewan parts of the Cypress Hills preserve are drawn (it continues into Alberta; Fort Walsh National Historic Site is part of it). RASC also lists Old Man on His Back (a Nocturnal Preserve), which has no open outline, so it is named in the panel but not mapped. No artificial sky-brightness layer: the VIIRS-based World Atlas is not openly licensed. The drive to a preserve is to the nearest campground inside one.
- **Hospitals** are Statistics Canada's 2020 list. Rural emergency departments have had temporary closures since.
- **What if this closed?** is a scenario the visitor chooses on Hospital access or Courts & police, not a plan anyone has announced. Each place falls back to the next of the three hospitals (or courthouses) the pipeline routed for it; a place whose three are all closed shows "more than" its third drive, never a guess. Only the drive changes: it says nothing about beds, staff, court sittings or waiting times. The Town Report and Town Finder always keep the real values.
- **Climate projections** are model output, not a record: Environment and Climate Change Canada's CMIP6 downscaled scenarios (CanDCS-U6, 26 models, about a 10 km grid), as 30-year averages of the change from 1971–2000 for 2021–2050, 2041–2070 and 2071–2100, under low (SSP1-2.6) and high (SSP5-8.5) emissions, each as the models' median and 10th–90th percentile. They are always shown as a range, hatched, with a "projection" badge. Between windows the map and chart interpolate; 1971–2000 is zero by definition. To continue the station record, the map and chart add the stations' own mean 1971–2000 anomaly so both read against 1961–1990 (the panel's table and the Town Report do not). The province band averages the places' percentiles, slightly wider than the spread of an average. ClimateData.ca has more indices from the same models (days above 30 °C, frost-free season), but its terms reserve all rights, so they are not used. Projections never rank towns.
- **Outlooks** are published forecasts, shown with their issue and valid times and dropped once the valid time has passed. MSC's thunderstorm outlook is experimental and issued only from May to October. CWFIS's fire danger class comes from the SCRIBE weather forecast for the day it names, and some of the atlas's places fall outside the area it rates. The smoke forecast is the RAQDPS model's highest fire-smoke PM2.5 over the day it covers, at the model grid cell of each place.
- **Flood-prone land** is the Water Security Agency's own mapping of a 1:500-year flood (a 0.2% chance in any year) in the communities it has studied, with the floodway and flood fringe where the Flood Damage Reduction Program drew them. It is a hazard map, not a forecast, and most of the province has none: no shading does not mean no risk.
- **Doctors & clinics**: a clinic on the map is **not a doctor taking new patients**; many family practices have closed their lists, and rural sites may open on certain days or be staffed by a nurse practitioner. The Saskatchewan Health Authority's clinics and primary health care centres come from Statistics Canada's 2020 ODHF list (hospitals, imaging, labs, dental, eye, chiropractic, public-health, mental-health and specialist sites are left out by type and name; sites the file gives no point for are put at their town's centre, **approximate**), joined with OpenStreetMap's medical clinics, doctors' offices and nurses (a site in both counts once, matched by distance and name, so a few may be doubled or wrongly merged). Neither list has most private family practices (Yorkton, Melfort and Kindersley show none), so a place with no clinic mapped but a hospital in town counts that hospital as its nearest clinic: **inferred**, since its doctors usually practise at or beside it, and the Town Report says so. Pharmacies are OpenStreetMap only. "In town" uses Daily needs' town limits and 1 km slack; Daily needs' own clinic ✓ is OpenStreetMap only, so this layer can count more. The health authority posts temporary emergency-department and service disruptions only as notices on its [service disruptions page](https://www.saskhealthauthority.ca/news-events/service-disruptions), not as data, so they are **not mapped**. No open list of doctors accepting patients is published. For health advice any time, [HealthLine 811](https://www.saskatchewan.ca/residents/health/accessing-health-care-services/healthline) is a free 24-hour line staffed by nurses.
- **Weekend Reach** uses one OSRM table per place to every drivable campground within 400 km, kept if within 4 h. The rolling ring on the map is only a guide; the arcs are the drive times.
- **Workday Reach** and the Finder's **Short commute** use OSRM's free-flow drive from the centre of the place you live to the centre of the place you work (home → work; the two directions differ by a few minutes at most). Rush hour, winter roads, construction and where in town you live or work are not counted, so real commutes run longer; the demo router is also cautious on highways (Regina to Moose Jaw comes out at 59 min). Only the atlas's 62 places are counted, not the farms, acreages and hamlets between them. Each place's Finder rank uses your saved weights; with every weight at zero no rank is shown. The workplace and limit are saved in this browser.
- **Campgrounds** outside the national parks come from OpenStreetMap and can be missing; Parks Canada's individual campsites are grouped into campgrounds. Provincial park campgrounds have no open point dataset, so OSM stands in. Seasons and closures are not in the data.
- **Smoke & air**: a smoke day is a calendar day (local standard time) whose 24-hour average PM2.5 is above 25 µg/m³, the WHO's 2005 24-hour guideline (Canada's 2020 ambient standard, CAAQS, is 27). Fine particles also come from traffic, industry and winter inversions, so not every such day is smoke, though most fall May–September. A day needs 18 of its 24 hourly readings; a station-year counts only when 75 % of its days and 75 % of its May–September days are valid, so some years are missing (for example Saskatoon 2003, Prince Albert 2008 and 2015). Where two instruments ran side by side, each hour comes from the one with more readings that year; Regina's two station ids (080110, then 080111) are joined into one record. Only six places monitor PM2.5 (Regina, Saskatoon, Prince Albert, Swift Current, Estevan, Buffalo Narrows), so a place's smoke days are **borrowed** from the nearest within 150 km, named in its report; places farther away show none. ECCC's archive holds Saskatchewan data from 2001 to **2023**: its 2024 file has no Saskatchewan rows yet, so the heavy 2024–2025 smoke seasons are not in the layer; re-running `npm run data smoke` picks them up once published.
- **Fire scars** are mapped outlines only where the National Burned Area Composite has one: fires of 200 ha or more, 1972 to its latest year (2024). Outlines are simplified to about a sixth of each burn's width, and the composite's area (less unburned islands) can differ from the reported size. Every other fire, and every fire after the composite's latest year, is a circle of the right area, not its real shape; the tooltip says which. Tornado counts depend on who or what was there to spot them. The two tornado records use different scales (Fujita to 2009, Enhanced Fujita from 2017), nothing open covers 2010–2016, and NTP track ends are estimated from length and direction.
- **Hail**: swath sizes are the radar's MESH (Maximum Expected Size of Hail), an estimate from the storm's structure, not a measured stone; the 2022 swaths come without a size. Only three summers of radar swaths are open (2022–2024), so the counts and the Finder's Less hail are a short record. Counts depend on radar coverage and, for the research database, on who was there to report hail. A long swath that started in Alberta or ended in Manitoba is cut to the part inside the query box. A research-database storm whose point was off the map (one, Swift Current 2026) is placed at the atlas town it is named after (inferred); one with no location is left out. Hail figures in crop-insurance and home and car insurance claims on the prairies; the layer shows storms, not claims or premiums.
- **What grows here** is a satellite classification (about nine fields in ten right), and each ~2 km square shows only its most common class, so small fields, sloughs, shelterbelts and farmyards vanish. It covers the farm belt only (to about 55–56° N), and cloud leaves gaps. Year-to-year shares are taken over the land mapped in every year. “Other crops and fallow” includes fields too wet to seed, which is why 2010 and 2011 stand out.
- **The power grid** is what OpenStreetMap's mappers have drawn: SaskPower publishes no open map, many lines carry no voltage, and some substations, smaller plants and most distribution lines are missing. A place's report gives the nearest mapped line and substation from its town limits; power is not in the Finder.
- **Drought**: the Canadian Drought Monitor is a consensus map drawn by scientists from many indicators, not a measurement, and its edges are generalised. It is read on a 10 km grid in the map service's Web Mercator projection, so edges are blocky; a place takes the category of the cell its centre is in, so a town near an edge can read one step off. Until early 2004 the maps covered only the agricultural south (the north shows as not analyzed). Province shares are of land and lakes, by true area. The Finder's Fewer drought months counts months at D2 (severe) or worse over the last ten years of maps.
- **Treaty boundaries** are Canada's depiction; First Nations' understanding of their territories and of the treaty promises can differ.
